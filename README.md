# BCTok — site public

Site statique (GitHub Pages) exigé par TikTok for Developers pour l’app : page d’accueil,
conditions d’utilisation et politique de confidentialité.

URL : <https://bcollignonecv.github.io/bctok/>

Le code de l’application elle-même est dans un dépôt séparé.

## Publication
GitHub → Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.

## Vérification TikTok
Si TikTok demande de vérifier l’URL (« URL prefix »), télécharger le fichier de signature fourni
par le portail développeur et le déposer à la racine de ce dépôt, puis pousser.
